# PuzzleNumbers

Calculadora de combinaciones de lotería (Melate, Chispazo, Tris o reglas propias), con el histórico oficial de resultados de Lotería Nacional.

- Página: https://defsilentdead.github.io/PuzzleNumbers/
- `historico-loteria.json.gz` se actualiza cada hora con un flujo de n8n cuando hay concursos nuevos.
- Fuente de los datos: https://www.loterianacional.gob.mx/Documentos/Historicos/
